# OroujiLab Learning

**Free, research-led educational resources in genomics, epigenomics and translational oncology.**

Website (deployment pending): https://oroujilab.github.io/learn/

This public repository contains the **reviewed teaching website source**, selected original scientific diagrams, synthetic educational datasets, and computational exercises. It is separate from the private OroujiLab development workspace.

## Learning pathways

- Computational genomics and reproducible analysis
- Experimental epigenomics: ATAC-seq, CUT&RUN and CUT&Tag
- Cancer biology and organoid models
- Translational oncology and evaluation of biological evidence

## Website

The website is built with [Quarto](https://quarto.org) and deployed with GitHub Pages using the automated workflow in `.github/workflows/deploy.yml`. Genomics demonstrations using BED, bedGraph and small matrix TSV files process examples in the browser; large indexed BigWig and Hi-C data require appropriate external viewers.
